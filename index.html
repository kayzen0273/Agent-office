Mode Tamu

Masuk ke kantor yang sama dengan pengguna lain secara real-time lewat Supabase Realtime. Siapa pun yang memakai Project URL Supabase dan kode ruang yang sama akan tampil sebagai karakter di kantor ini, bisa berjalan, melambai, dan chat. Hanya nama, warna, posisi, dan pesan chat biasa yang dikirim. API key Gemini, hasil kerja, dan skill tetap di perangkatmu.

Warna baju

Hubungkan Gemini

Buat API key gratis di Google AI Studio, lalu tempel di sini. Kunci hanya disimpan di browser ini dan dikirim langsung ke Google, tidak lewat server lain.

Hasil

Skill agen

Unggah skill (file SKILL.md, .md, .txt, atau paket .zip / .skill) atau tempel isinya. Skill yang aktif dipakai agen saat Gemini terhubung. Tersimpan hanya di browser ini.

Supabase

Hasil kerja agen (termasuk gambar), skill, daftar tugas di papan, dan riwayat chat disimpan di proyek Supabase Anda, jadi sama di semua perangkat. Buat proyek gratis di supabase.com, jalankan SQL di bawah sekali di SQL Editor, lalu isi kolom ini. Yang dipakai adalah anon key (bukan service key).
